# Repositório de Projetos - Laboratório de Medição e Experimentação de Software

## Sobre este repositório

Este repositório centraliza os projetos desenvolvidos pelo time na disciplina **Laboratório de Medição e Experimentação de Software**.

Cada pasta representa um projeto/laboratório com seu próprio escopo, dados, código-fonte, documentação e relatórios.

## Objetivo

Organizar, versionar e documentar os entregáveis do time, incluindo:

- coleta automatizada de dados;
- processamento e análise de métricas;
- geração de arquivos CSV;
- produção de gráficos e visualizações;
- elaboração de relatórios técnicos;
- evolução incremental por sprint.

## Estrutura do repositório

- `Lab01/` -> primeiro projeto do time;
- `Lab01/docs/` -> enunciado, metodologia e tarefas (ver `Lab01/docs/README.md` para o índice completo);
- `Lab01/src/` -> código-fonte de coleta, métricas e análise;
- `Lab01/data/` -> dados brutos, processados e snapshots;
- `Lab01/reports/` -> rascunhos, figuras e relatório final;
- `Lab01/tests/` -> testes e validações.
