# Soluções de referência

Esta pasta será usada para validar as suítes e apoiar a avaliação de equivalência das katas.

> Durante a coleta, as soluções de referência não podem ficar acessíveis aos participantes. O grupo deve definir na S01 um mecanismo de custódia compatível com essa restrição. Elas somente devem ser incorporadas ao repositório compartilhado depois que todos os trials forem encerrados, caso sua publicação seja necessária para a replicação.
