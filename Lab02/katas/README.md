# Katas experimentais

Esta pasta contém os seis objetos experimentais:

```text
katas/
├── K01/
├── K02/
├── K03/
├── K04/
├── K05/
└── K06/
```

Cada kata deverá possuir a mesma organização interna:

```text
KXX/
├── README.md          # Enunciado da tarefa
├── src/               # Esqueleto inicial e código de produção
├── tests/             # Testes automatizados de aceitação
└── config/            # Configuração estritamente necessária
```

Os enunciados não devem revelar a solução de referência. Dependências de rede, serviços externos e arquivos particulares de um participante não são permitidos.
