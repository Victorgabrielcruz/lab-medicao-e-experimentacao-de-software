# Código-fonte de apoio

| Pasta | Responsabilidade técnica |
|---|---|
| `collection/` | Cronometragem e registro dos trials |
| `metrics/` | Extração das métricas de RQ1–RQ3 |
| `processing/` | Consolidação dos dados brutos |
| `validation/` | Regras de integridade e qualidade dos dados |
| `analysis/` | Estatística descritiva e inferencial |
| `dashboard/` | Visualização dos resultados |
| `environment.py` | Inventário de ferramentas/hardware e validação dos tratamentos |

Essa separação mantém coleta, transformação e análise independentes e testáveis.
