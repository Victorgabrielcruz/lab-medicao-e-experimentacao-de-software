# Código final dos trials

Esta pasta preservará o estado final do código produzido em cada tentativa.

Organização recomendada:

```text
trials/
└── PXX/
    └── KXX_<tratamento>/
        ├── src/
        └── trial.json
```

Use `ai` ou `manual` como tratamento. O diretório deve corresponder ao `trial_id`, à Issue e ao commit registrados no dataset. Não inclua aqui conversas, tokens, credenciais ou informações pessoais.
