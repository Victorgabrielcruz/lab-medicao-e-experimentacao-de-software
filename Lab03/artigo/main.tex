\begin{abstract}
This study computes the four DORA metrics for 500 popular GitHub repositories
using GitHub Actions over twelve months, treating stable releases as
deployments and workflow runs as the source of CI failures. Most repositories
fall into the High or Medium categories. Deployment frequency and change
failure rate are positively correlated, weakly for the CI variant
(rho=0.155) and strongly for the corrective-release variant (rho=0.799).
Contributors and age are associated with some metrics after Holm correction,
with no uniformly superior profile. Changing only the failure-rate definition
changes 38.33\% of overall categories, against 14.53\% for lead time. The
corrective-release heuristic reaches F1=0.933 against a manual gold sample.
\end{abstract}
\begin{resumo}
Este estudo calcula as quatro métricas DORA para 500 repositórios populares do
GitHub com Actions, em doze meses, tratando releases estáveis como implantações
e execuções de workflows como fonte de falhas de CI. A maioria dos projetos
fica nas classes High ou Medium. Frequência de implantação e taxa de falha têm
associação positiva, fraca na variante de CI (rho=0,155) e forte na de
releases corretivas (rho=0,799). Contribuidores e idade se associam a algumas
métricas após Holm, sem perfil uniformemente superior. Trocar apenas a
definição de taxa de falha altera 38,33\% das classes gerais, contra 14,53\%
para o lead time. A heurística de corretivas atinge F1=0,933 contra uma
amostra-ouro manual.
\end{resumo}
