# Artigo do Lab03

Seções do artigo em LaTeX, prontas para o projeto no Overleaf com o template da SBC (S01-22).

| Arquivo | Conteúdo |
|---|---|
| `introducao.tex` | Seção 1: introdução e hipóteses informais das RQ01 a RQ04 |
| `referencias.bib` | Referências citadas nas seções acima |

No Overleaf, cada seção entra com `\input{introducao}`, e as referências com `\bibliography{referencias}`.

Template SBC disponível na galeria do Overleaf, atribuído à Sociedade Brasileira de Computação:
[SBC Conferences Template](https://www.overleaf.com/latex/templates/sbc-conferences-template/blbxwjwzdngr).
O repositório ainda contém somente a introdução e as referências; o projeto completo
no Overleaf exigido pela #150 ainda precisa ser criado e validado.

As hipóteses foram escritas antes da coleta dos dados. A data do commit que criou cada arquivo de hipóteses registra esse momento.
